# MAGOG SARL - Ingénierie Hydraulique & Génie Civil Construction

Plateforme web officielle et vitrine d'ingénierie pour **MAGOG SARL**, bureau d'études et d'exécution spécialisé dans les infrastructures hydrauliques (AEP, châteaux d'eau, forages grande profondeur, assainissement) et le génie civil au Bénin et en Afrique de l'Ouest.

---

## 🌟 Points Clés & Fonctionnalités

- **Design Premium & Identité Institutionnelle** : Conforme aux standards visuels BTP & Ingénierie lourde.
- **Navigation Multi-Pages & Hash Routing** :
  - Accueil (Hero interactif, Chiffres clés, Pôles d'expertise, Témoignages)
  - Ingénierie Hydraulique & AEP
  - Génie Civil & Bâtiment
  - Réalisations & Chantiers de référence
  - Méthodologie & Démarche Qualité QHSE
  - Contact & Localisation avec intégration Google Maps
- **Outil d'Estimation Budgétaire Interactif** : Calculateur dynamique de coût prévisionnel selon les paramètres du projet.
- **Demande de Devis en Ligne** : Modale complète de soumission de cahier des charges et devis technique.
- **Canaux d'Appel d'Urgence & WhatsApp** : Boutons d'action rapide pour contact direct avec la direction technique.

---

## 🛠️ Stack Technique

- **Framework** : React 18 + Vite 6
- **Styling** : Tailwind CSS + PostCSS + Autoprefixer
- **Icônes** : Lucide React
- **Déploiement** : Vercel / GitHub Pages

---

## 🚀 Installation & Développement Local

1. Cloner le dépôt :
```bash
git clone https://github.com/junesnatan/magog-sarl.git
cd magog-sarl
```

2. Installer les dépendances :
```bash
npm install
```

3. Lancer le serveur de développement :
```bash
npm run dev
```

4. Compiler pour la production :
```bash
npm run build
```
